# Compliance baselines

Complete baselines: a broad Linux hardening baseline modelled on OpenSCAP and CIS, and a managed-RHEL baseline with a tag-based selection model.

| Example | Description | Checks |
|---|---|---|
| [Linux hardening baseline](linux-hardening.md) | A broad server hardening baseline for current Linux distributions, structured like the public hardening guides of the SCAP Security Guide (OpenSCAP) and the CIS benchmarks: file systems, services, network parameters, auditing, logging, access control, accounts, file permissions, boot and maintenance. | 227 |
| [Managed RHEL baseline](managed-rhel.md) | A complete managed-OS baseline for RHEL 8/9, ported from the module-based checkmate 1.x. | 79 |
