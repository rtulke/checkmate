# Getting started

checkmate reads a **policy**, a YAML file with a list of **checks**. Each check runs a command and compares its result with an expectation. The result is a report and an exit code you can use in scripts and pipelines.

1. [Install checkmate](installation.md): a single binary, no runtime dependencies.
2. [Write your first policy](first-policy.md) in five minutes.
3. Understand [how checks are evaluated](concepts.md): statuses, errors and exit codes.

Then browse the [examples](../examples/index.md) for checks you can reuse right away.
