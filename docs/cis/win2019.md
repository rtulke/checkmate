# CIS Microsoft Windows Server 2019

Automated checks for 424 recommendations of the CIS Microsoft Windows Server 2019 benchmark (version 4.0.0), converted from the goss audit content of the ansible-lockdown project. Check names describe what is verified; the recommendation number is in the ID and the description. Select profiles with tags, e.g. `--tags cis-level1-member-server`. Run elevated (as administrator). Every check collects its own value (registry, secedit, auditpol, services, firewall). Set `-e cis_windows_role=dc` on domain controllers and `-e cis_windows_role=standalone` on servers that are not domain members (adds the password and lockout rules the domain sets).

**Policy:** [`cis/win2019.yml`](https://github.com/rtulke/checkmate/blob/main/cis/win2019.yml) · **Benchmark version:** 4.0.0

Run in an elevated PowerShell (as administrator). Every check collects its own value:

```powershell
checkmate run cis/win2019.yml --tags cis-level1-member-server
checkmate run cis/win2019.yml --tags cis-level1-domain-controller -e cis_windows_role=dc
checkmate run cis/win2019.yml -e cis_windows_role=standalone
```
