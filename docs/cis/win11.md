# CIS Microsoft Windows 11 Enterprise

Automated checks for 471 recommendations of the CIS Microsoft Windows 11 Enterprise benchmark (version 3.0.0), converted from the goss audit content of the ansible-lockdown project. Check names describe what is verified; the recommendation number is in the ID and the description. Select profiles with tags, e.g. `--tags cis-level1-member-server`. Run elevated (as administrator). Every check collects its own value (registry, secedit, auditpol, services, firewall). Set `-e cis_windows_role=dc` on domain controllers. On domain members set `-e cis_windows_domain_joined=true`; the domain policy then sets password and lockout settings.

**Policy:** [`cis/win11.yml`](https://github.com/rtulke/checkmate/blob/main/cis/win11.yml) · **Benchmark version:** 3.0.0

Run in an elevated PowerShell (as administrator). Every check collects its own value:

```powershell
checkmate run cis/win11.yml --tags cis-level1-workstation
checkmate run cis/win11.yml --tags cis-level-2 -e cis_windows_domain_joined=true
```
